# Emergent Quantum Matter Across Scales — Aspen Winter 2027

Website for the Aspen Center for Physics winter conference *Emergent Quantum Matter Across Scales: From Moiré Platforms and Quantum Simulation to AI-Driven Theory*, February 7–12, 2027.

Static multi-page site (HTML/CSS/JS, no build step):

- `index.html` — Home / overview / organizing committee
- `speakers.html` — Speakers
- `schedule.html` — Schedule
- `registration.html` — Registration (apply, lodging, location, travel)

## Hosting on GitHub Pages

Push to the `main` branch, then in **Settings → Pages** set the source to `main` / root. The site publishes at the configured GitHub Pages URL.
